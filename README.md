# StoreFactory Web Simulator

**Status: Development (Alpha)**

Welcome to the **StoreFactory Web Simulator** project. This repository contains the source code for the Master Thesis "Increasing Performance of the Textile Production Chain Applied to the StoreFactory Project".

This web application serves as a **Digital Lab** to visualize and simulate material shrinkage parameters for automated textile production.

## Technology Stack

*   **Framework:** ASP.NET Core 1.1 (C#)
*   **Frontend:** Bootstrap 3.3.7, jQuery 2.2.4
*   **Platform:** Cross-Platform (Runs on Windows, macOS, Linux)
*   **Tools:** Visual Studio Code / Visual Studio 2015 Update 3

## Project Status

- [ ] **Phase 1: Foundation** (Setup & Layout)
- [ ] **Phase 2: Logic Core** (Calculation Engine)
- [ ] **Phase 3: Interactive UI** (Simulator Dashboard)
- [ ] **Phase 4: Visualization** (Canvas Renderer)
- [ ] **Phase 5: Analytics** (Charts & Results)

## Setup Instructions

1.  Install .NET Core 1.1 SDK.
2.  Run `dotnet restore`.
3.  Run `dotnet run`.
4.  Open `http://localhost:5000` in your browser.
